# 💜 Bellezza Studio

### Modern Beauty Salon Appointment Booking System

A responsive and user-friendly beauty salon booking application developed with React and Vite.

This project allows users to register, log in, book appointments with specialists, manage upcoming bookings, cancel appointments, and prevent double-booking conflicts through a clean mobile-first interface.

---

## ✨ Features

🔐 User Authentication
- Register new accounts
- Login with existing credentials
- User-specific appointment storage

📅 Appointment Management
- Book appointments
- Choose specialists
- Select date and time
- View upcoming appointments
- Cancel appointments

⏰ Smart Scheduling
- Prevents double bookings
- Real-time unavailable slot detection
- Specialist-based scheduling

🎨 Modern User Experience
- Mobile-first design
- Dark mode support
- Smooth navigation
- Responsive layout

💾 Data Persistence
- LocalStorage integration
- User data saved between sessions
