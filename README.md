# Bellezza Studio

A React-based beauty salon appointment booking application.

## Features

- User Registration & Login
- Appointment Booking
- Appointment Cancellation
- Appointment Rescheduling
- Specialist Selection
- Dark Mode
- Search Services
- Category Filtering
- Local Storage Persistence

## Technologies

- React
- JavaScript
- CSS
- Vite
