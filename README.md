# Bellezza Studio Appointment Booking System

React-based beauty salon appointment booking application with user authentication, specialist scheduling and appointment management.

## Features

- User registration and login
- Appointment booking
- Specialist selection
- Time slot conflict prevention
- Appointment cancellation
- User-specific appointment storage
- Dark mode
- Responsive mobile-first UI

## Technologies

- React
- Vite
- JavaScript
- CSS
- LocalStorage
